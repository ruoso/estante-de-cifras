# app/

The PWA: everything the user sees (DIRECTION §3.7). JavaScript and React,
with git through isomorphic-git in a Web Worker and the music core carried
over from Explore Chords.

Reserved by `foundation.monorepo`; the tooling and first scaffolding land in
`foundation.app_tooling`, and the feature streams fill it from there. The app
and the service share no code (DIRECTION §3.6), only the HTTP API (`../api/`)
and the format (cifra.md).
