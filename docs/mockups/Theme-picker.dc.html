The theme picker

Theme and language live together in a Preferences section of the account screen, reached from the header and present before you sign in. Four theme choices — Automatic, Estante, Caderno, Palco — each named in words with a live preview, the chosen one marked by a word, never colour alone. The columns are drawn in the theme each would apply.
