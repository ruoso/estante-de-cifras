The theme picker

Theme and language live together in a Preferences section of the account screen, reached from the header and present before you sign in. Four theme choices — Automatic, Estante, Caderno, Palco — each named in words with a live preview, the chosen one marked by a word, never colour alone. The columns are drawn in the theme each would apply. Between theme and language sit density — Compact, Comfortable, Roomy, each with a sample of a chart line — and how chord diagrams are drawn, by hand and neck, with one live diagram drawn as the pair chosen; the tablet is drawn Roomy and the computer Compact. Last comes your name — the name your saves carry, or Not set yet before the first save asks — with Change, which opens a small dialog prefilled with it; saves from then on carry the new name and those already saved keep theirs. On the computer it sits below the two columns, across both.
