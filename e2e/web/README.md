# e2e/web

The e2e-web harness: Playwright against the compose stack (the app served by
the service on its one origin), on phone, tablet and computer viewports, with
axe at WCAG 2.1 AA on every screen a task touches, and offline where the task
is about offline (DIRECTION §3.6, tasks/refinements/README.md).

Reserved by `foundation.monorepo`; filled by `foundation.e2e_web`.
